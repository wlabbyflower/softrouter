# LZCWrt 指南

`LZCWrt` 是面向懒猫微服的软路由应用方案，可以在微服中创建 iStoreOS、OpenWrt 或 ImmortalWrt 旁路由实例。

## 阅读顺序

1. [LZCWrt 旁路由完整指南](guide.md)

## 应用包

- 当前内置包：[`../../../packages/lzcwrt/cloud.lazycat.app.lzcwrt-v0.1.6.lpk`](../../../packages/lzcwrt/cloud.lazycat.app.lzcwrt-v0.1.6.lpk)

## 注意事项

- 仅限微服连接有线网络使用。
- LZCWrt 要求微服系统版本不低于 `1.5.0`。
- 创建实例前请确认局域网网关、子网、DNS 和空闲 IP。
